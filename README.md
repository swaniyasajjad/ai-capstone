# AI Capstone

A simple AI-assisted development capstone project demonstrating the use of modern AI tools to plan, build, and improve software projects.

## Features

- AI-assisted development
- Git version control
- Markdown documentation
- Beginner-friendly project structure

## Tech Stack

- Node.js
- Git
- Markdown
- GitHub

## Getting Started

### Prerequisites

Before running this project, make sure you have:

- Node.js (LTS)
- Git

### Installation

1. Clone the repository.

```bash
git clone https://github.com/your-username/ai-capstone.git
cd ai-capstone
```

1. Install the dependencies.

```bash
npm install
```

1. Start the project.

```bash
npm start
```
